# 漁獲管理システム（配布用）

鮮魚受入伝票の登録と、過去の水揚げの確認・グラフ表示ができるシステムです。
Windows のPC1台で動きます（インストール作業やインターネット接続は不要です）。

このリポジトリは**配布専用**です。配布用ZIPは [Releases](../../releases/latest) からダウンロードしてください。

## 導入方法

1. [最新の Releases](../../releases/latest) から `G-System-vX.Y.Z.zip` をダウンロードします。
2. ZIPを右クリックして「すべて展開」を選びます。途中でパスワードを聞かれたら、別途お知らせしたパスワードを入力します。
   - ZIPをダブルクリックして中身を開いただけの状態では動きません。必ず「すべて展開」してください。
3. 展開したフォルダの中にある「ショートカット作成.bat」をダブルクリックします。デスクトップに「漁獲管理システム」ができます。
4. デスクトップの「漁獲管理システム」をダブルクリックすると、ブラウザで画面が開きます。

詳しい使い方は、ZIPの中の「取扱説明書.xlsx」をご覧ください。

## 動作環境

- Windows 10 / 11（64bit）
