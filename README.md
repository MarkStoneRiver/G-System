# 漁獲管理システム（配布用）

鮮魚受入伝票の登録と、過去の水揚げの確認・グラフ表示ができるシステムです。
Windows のPC1台で動きます（インストール作業やインターネット接続は不要です）。

このリポジトリは**配布専用**です。配布用ZIPは [Releases](../../releases/latest) からダウンロードしてください。

## 導入方法（はじめての方）

1. [最新の Releases](../../releases/latest) から `G-System-vX.Y.Z.zip` をダウンロードします。
2. ZIPを右クリックして「すべて展開」を選び、展開先を `C:\` にして「展開」を押します。途中でパスワードを聞かれたら、別途お知らせしたパスワードを入力します。
   - `C:\漁獲管理システム` フォルダができます。このフォルダでシステムを使い続けるので、削除しないでください。
   - ZIPをダブルクリックして中身を開いただけの状態では動きません。必ず「すべて展開」してください。
3. `C:\漁獲管理システム` の中にある「漁獲システム（アップデート）.bat」をダブルクリックします。デスクトップに「漁獲管理システム」ができます。
4. デスクトップの「漁獲管理システム」をダブルクリックすると、ブラウザで画面が開きます。

詳しい使い方は、ZIPの中の「取扱説明書.xlsx」をご覧ください。

## アップデート方法（すでにお使いの方）

1. 新しいZIPをダウンロードし、右クリック→「すべて展開」します。展開先はどこでもかまいません（ダウンロードフォルダのままで大丈夫です）。
2. 展開したフォルダの中の「漁獲システム（アップデート）.bat」をダブルクリックし、「アップデートしますか？」で Enter を押します。
3. 「アップデートが完了しました。」と表示されたら、何かキーを押して閉じます。手順1で展開したフォルダは削除してかまいません。

今お使いのフォルダ（例：`C:\漁獲管理システム`）が新しいバージョンになり、伝票などのデータはそのまま残ります。システムが動いている場合は、自動で終了してからアップデートします。

> v1.0.3 以前には「漁獲システム（アップデート）.bat」がありません（「ショートカット作成.bat」という名前でした）。新しいZIPの中のものを使ってください。

## 動作環境

- Windows 10 / 11（64bit）
