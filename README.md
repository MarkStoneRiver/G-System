# 漁獲管理システム（配布用）

鮮魚受入伝票の登録と、過去の水揚げの確認・グラフ表示ができるシステムです。
Windows のPC1台で動きます（インストール作業やインターネット接続は不要です）。

このリポジトリは**配布専用**です。配布用ZIPは [Releases](../../releases/latest) からダウンロードしてください。

## 導入方法（はじめての方）

1. [最新の Releases](../../releases/latest) から `G-System-vX.Y.Z.zip` をダウンロードします。
2. ZIPを右クリックして「すべて展開」を選びます。途中でパスワードを聞かれたら、別途お知らせしたパスワードを入力します。
   - ZIPをダブルクリックして中身を開いただけの状態では動きません。必ず「すべて展開」してください。
3. 展開したフォルダの中にある「漁獲システム（アップデート）.bat」をダブルクリックします。デスクトップに「漁獲管理システム」ができます。
4. デスクトップの「漁獲管理システム」をダブルクリックすると、ブラウザで画面が開きます。

詳しい使い方は、ZIPの中の「取扱説明書.xlsx」をご覧ください。

## アップデート方法（すでにお使いの方）

1. 画面右上の「終了」ボタンでシステムを終了します。
2. 新しいZIPをダウンロードし、右クリック→「すべて展開」で、前と同じ場所（例：`C:\`）に展開します。「ファイルの置換またはスキップ」と表示されたら「ファイルを置き換える」を選びます。
3. 「漁獲管理システム」フォルダの中の「漁獲システム（アップデート）.bat」をダブルクリックします。

入力したデータはそのまま引き継がれます。別の場所に展開した場合も、手順3で「前のバージョンのデータを引き継ぎますか？」と聞かれるので、Enter を押せば引き継げます。

> v1.0.3 以前には「漁獲システム（アップデート）.bat」がありません（「ショートカット作成.bat」という名前でした）。新しいZIPの中のものを使ってください。

## 動作環境

- Windows 10 / 11（64bit）
